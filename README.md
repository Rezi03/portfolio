# Portfolio — Rezo Sabashvili

Site statique publié sur GitHub Pages : https://rezi03.github.io/portfolio/

- `index.html` — page française
- `en/index.html` — page anglaise
- `recommandations.html`, `en/recommendations.html` — lettres de recommandation
- `css/style.css` — feuille de style unique
- `assets/` — CV, lettres et portrait

Aucun JavaScript, aucune dépendance. Les polices Inter et Source Serif 4 sont
chargées depuis Google Fonts. Le sélecteur de langue est un simple lien.
