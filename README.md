# Portfolio — Rezo Sabashvili

Site statique publié sur GitHub Pages : https://rezi03.github.io/portfolio/

- `index.html` — page unique, française
- `en/index.html` — page unique, anglaise
- `recommandations.html`, `en/recommendations.html` — lettres de recommandation
- `css/style.css` — feuille de style unique
- `assets/` — CV, lettres et portrait

Le détail des postes, d'Axone et de Finteker s'ouvre dans une fenêtre
`<dialog>` native. C'est le seul JavaScript du site, une vingtaine de lignes
en bas de page. Le sélecteur de langue est un simple lien. Aucune dépendance.
Les polices Inter et Source Serif 4 sont chargées depuis Google Fonts.
